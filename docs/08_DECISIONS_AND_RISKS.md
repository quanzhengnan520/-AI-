# 08｜已确认决定、待验证假设、必要的用户操作

## A. 已确认的产品方向（先不要反复推翻）
- 项目最终是**有独立物理载体的 AI 智能硬件**，日常可脱离手机使用，目标是蜂窝独立联网；手机用于第一版软件与软硬件融合体验验证。
- 首代以**个人第二大脑**为核心：录入→可信记忆→跨时间关联→有依据分析→用户可控提醒。
- 用户必须拥有最终判断权，原话/事实/推测分别管理，记忆可纠错，有历史版本和人物/事件/任务关联。
- 长期适配 iPhone、Android、Windows、未来 AI 硬件的同一 API；近期 iPhone 优先。
- 手动/自动整理/全天陪伴是长期三模式愿景，但 POC 不冒充已实现常开感知。

## B. 本文为推进开发作出的暂定工程选择（可由测试调整）
- Expo React Native + TS；FastAPI + SQLite；单用户本地优先；Mock 首启；默认轻量全文检索；API 和 ASR 独立适配。
- 为了验证业务，不先建设商业订阅、用户增长、硬件 B.O.M. 采购或量产链路。
- 默认原始资料保留 30 天。长期留存“原话摘录”单独征求授权；派生智能记忆的删除政策透明。
- 安全配对不依赖真实多租户平台；后续试用者扩大时，必须重新审核隔离与运营策略。

## C. 技术与市场上**尚不能宣称已解决**
1. iPhone 真实后台录音能持续多久、系统中断后如何恢复。
2. 中文语音识别在会议室/车内/多人场景中的质量与成本。
3. 记忆抽取/检索对不同类型对话的误报率与漏报率。
4. 低打扰主动提醒的真实长期使用价值。
5. 用户愿否为额外穿戴设备付费，以及该设备相比手机带来的独特价值。
6. 独立 4G 设备的模组选型、运营商/eSIM 商用条件、发热续航和声学系统。
7. 具体 BOM、量产/认证、硬件售价、订阅盈利和退货率。
8. 大模型提供商的数据处理、跨境传输、真实商务录音法律适用性。

## D. 用户将来需要亲自完成、Codex 不能代替的事项
- 在需要 iPhone **正式开发版/Ad Hoc/TestFlight** 时，注册或使用有权限的 Apple Developer Program 账户，并完成设备/签名步骤；标准会员费用约 99 美元/年，地区以官方结算为准。
- 用户自行选择可信模型 API 服务商并配置密钥，核对个人/客户资料是否允许上传。**不可把 API Key 发到聊天里**。
- 真机首次授权麦克风、通知；明确批准实际录音；确认参与者许可。
- 如果要把电脑服务部署到公网，由用户批准域名、TLS、访问策略与预算；默认不自动公开。
- 若未来与多人测试，先明确数据隐私通知、授权和删除政策，并核实目标地区的合规要求。

## E. 里程碑决策门
- M0 过关：继续 M1 还是修改 UI/范围？
- M1 过关：来源可核验是否成立？
- M2 过关：录音/转写表现是否足够支撑真实使用？
- M3 过关：与普通会议摘要工具相比，有无用户能感知的跨时间价值？
- M4 过关：主动提醒是否打扰、数据是否能掌控？
- M5 过关：继续硬件验证、优化软件，或缩小市场切口？

## F. 推荐架构取舍规则
有新问题时先问：是否影响“可证据追溯的长期记忆”核心闭环？不影响，则延后。不要因为某个 Jarvis 演示酷炫而扩展为桌面自动化助手。
