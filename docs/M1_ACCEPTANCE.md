# M1 验收方法与记录

只使用虚构资料。必测故事在 fixtures/m1_budget_story.json；不导入真实谈话。

## 手工验收路线

1. 按 README 启动后端和 Expo Web，进入“文字工作区 · M1”，生成单次码并配对。未配对时只能存本机草稿；直接访问私有 API 应返回 401。
2. 新建“王总表示项目预算预计为200万元。”，时间填 2026-10-01T14:00:00+08:00，人物“王总”，项目“星河示例项目”，事件“预算沟通”，批准同步并核对原文。
3. 新建“王总表示预算尚未得到公司批准。”，时间 2026-10-10T14:00:00+08:00；再建“王总表示目前只能考虑150万元。”，时间 2026-11-12T14:00:00+08:00；关联同一人物、项目和事件。三条独立存在，150万没有覆盖200万。
4. 检索预算、人物、项目；分别打开记录并抽取候选，默认 Mock。候选都有来源版本、原文证据、时间和审核状态，来源链接定位准确。
5. 确认第一条、驳回第二条、修改第三条候选；修改后仍待审核，原文不随候选改动。确认计划或假设后仍保留其语气。
6. 问“王总的项目预算有哪些记录？预算曾经获得批准了吗？”，应引用三个时间的原话，并明确无法确认获得批准。问“木星明天的天气是多少度？”，应拒绝猜测且无伪造引用。
7. 新建额外虚构记录，含 emoji 和前后空白，保存后核对原文保真及高亮。编辑后版本递增，旧候选不进入当前集合，旧来源版本仍能查看。两个窗口旧版本同时编辑，后提交应报冲突并保留输入。
8. 停止 API，或在开发工具只阻断 API 请求、保留 Expo 页面可加载。保存本机草稿，刷新后仍在；批准同步失败后仍待同步。恢复 API 点击重试，仅生成一条；连续点击、超时重发不得重复。未批准草稿不得发送。
9. 删除第7步额外记录，必须明确确认；正文、历史、候选不再可检索，其他三条预算不受影响，旧创建请求不能复活已删除记录。
10. 重启后端、刷新客户端，原文和审核状态仍在。退出配对、生成新码后可重新访问同一用户资料。旧 M0 演示导航、录音浮层和问答仍能使用且标为演示。

## 自动化复现

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check.ps1
.\services\api\.venv\Scripts\python.exe .\scripts\smoke_api.py
.\services\api\.venv\Scripts\python.exe .\scripts\smoke_m1.py
```

M1 HTTP 烟测用临时库，先迁移0001_m0，再升级至最新；配对码和令牌只在进程和临时文件中流转，不打印凭据、不调用云模型。

## 本轮实际结果

最终检查通过：后端111项、移动端54项、M1真实HTTP12场景、M1浏览器9场景；M0的HTTP6场景与浏览器12场景继续通过。格式、类型、Expo依赖与Web导出均通过。详见PROGRESS.md及本机.artifacts/verification/m1中的日志与截图。

9个浏览器场景依次是：一次性配对、三次预算原文保存、项目关联检索、候选确认/驳回/修改、拒绝无依据审批结论并定位引用、无关问题拒答、离线刷新及响应丢失恢复、编辑/确认删除不影响历史、无运行异常与外部HTTP请求。截图已经由主代理查看，测试仅使用合成资料和独立临时库。

可选浏览器复现需要已安装的Playwright和Microsoft Edge，先运行Expo Web：

```powershell
$env:M1_WEB_URL = 'http://localhost:8081'
node .\scripts\smoke_m1_ui.cjs
```

脚本自行迁移临时数据库并启动随机端口API，将浏览器业务请求代理到该隔离API，不写入日常资料库。无需准备配对码或导入夹具。若使用非默认Expo端口，将M1_WEB_URL改为终端实际地址。

浏览器操作由脚本驱动，只证明Web预览，不替代iPhone真机、安全存储和系统杀进程测试。旧版本编辑冲突通过API/组件测试验证；没有宣称两个真实手机已测试。Live Adapter只用伪造传输验证，没有实际模型质量评测。

## 已知范围

SQLite和本机草稿尚未生产加密；Web sessionStorage、AsyncStorage不用于真实秘密。草稿按单标签页使用，尚无跨标签页写锁。单用户设备认证不等于多租户产品；公网HTTPS、模型费用限额和生产部署未完成。关键词检索可能漏召回，Mock逐句抽取不理解复杂语义；最多搜索最新1000条、返回20条引用。删除不能保证磁盘残留或外部备份消失。M2及之后音频、任务、通知、跨记录推理、批量导出不在本次范围。
